# IT Support Lab Public Pages

This folder is a standalone static package for publishing the approved IT Support Lab privacy and support pages with GitHub Pages.

## Publish with GitHub Pages

1. Open GitHub in a browser and use the confirmed account `alexeis-itsupportlab`.
2. Create a new **public** repository named `it-support-lab-public`. Do not add a template, license, or unrelated files.
3. Upload only the contents of `store/github-pages/` to the repository root:
   - `index.html`
   - `privacy.html`
   - `support.html`
   - `README.md` (optional for the published site)
4. Commit those files to the default branch.
5. In the repository on GitHub, open **Settings > Pages**.
6. Configure deployment from the default branch and the repository root.
7. Wait until GitHub shows the published HTTPS URL, then verify all three pages on a phone and desktop browser.

## Security and privacy boundary

The public repository must contain only the three HTML pages and, optionally, this README. Do not upload application source code, social videos, creator photos, QR files, credentials, tokens, keystores, personal files, development configuration, or any other project content.

The pages use plain HTML and CSS. They contain no external JavaScript, external fonts, analytics, trackers, or cookies.
